# Lote futuro: programação e qualidade de repositório

## Escopo potencial
- Fluxos de implementação, refatoração segura, revisão de código e migração.
- Testes unitários, integração, contract tests, property-based testing e regressões.
- CI/CD, releases, rollback, observabilidade de builds e diagnóstico de falhas.
- Documentação técnica, ADRs, segurança de dependências e revisão de mudanças.

## Evitar sobreposição
Antes de adicionar uma skill, procurar no catálogo por linguagem, framework, tarefa e resultado. Não criar apenas outra versão de “code review” ou “write tests” sem um contexto operacional realmente distinto.

## Critério de aceite
Cada skill deve declarar contexto, entradas, passos executáveis, resultado esperado, casos negativos, recuperação e testes de roteamento. Lote ainda não implementado.
