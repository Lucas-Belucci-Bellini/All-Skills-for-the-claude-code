# Attribution and Licensing

This generated plugin contains skill directories sourced from the files in this repository.

- Preserve all source licenses, attribution, NOTICE files, and usage conditions.
- The root repository license does not automatically relicense third-party material.
- Review source repository terms before redistributing this bundle publicly.
- The REA skills reference https://github.com/morluto/rea; this bundle does not include or configure the REA runtime/MCP server.
- Analyze software and binary artifacts only when the user owns them or is authorized to inspect them.
- Sources whose license forbids redistribution are excluded by `excludedSources` in `tools/sync-skill-bundles.mjs`. Currently this covers Anthropic's proprietary `claude-security` plugin, which was removed from this repository.
