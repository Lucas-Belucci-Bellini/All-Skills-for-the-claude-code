3. Testing, debugging, and diagnostics.
4. Performance and resource-budget engineering.
5. Secure boundaries and interoperability.

## Six polyglot workflows

- Incremental language migration planning.
- Polyglot build and release reproducibility.

## Evidence and limitations

The language inventory is taken from the public profile's language matrix updated 2026-10-16. Detection in a public repository indicates evidence of use, not certification or equal proficiency. Each workflow requires validation against the actual language version, project toolchain, and runtime before a task can be considered complete.
