# Repository Skill Draft Specification Validator

## Purpose

`tools/validate-repository-skill-draft-spec.mjs` checks the structure and completeness of a draft specification generated by the scaffolder. It is a fail-closed quality gate: TODO placeholders, missing fields, weak evidence pointers, unsafe paths, invalid line ranges, duplicate evidence IDs, unverified license review, or incomplete duplicate review cause validation to fail.

## Usage

```sh
node tools/validate-repository-skill-draft-spec.mjs path/to/draft-spec.json
```

The command prints a JSON report and exits nonzero for an incomplete draft. A passing result is named `complete-for-human-review`, never `ready-for-human-review` or `approved`.

## Important boundary

The validator cannot establish that a claim is true, that a cited range supports it, that a license is legally compatible, or that semantic deduplication was done well. The license and duplicate-review fields are declarations by a human reviewer, not cryptographic proof. Review source content at the pinned commit independently.

Passing the validator does not modify skill manifests, generated bundles, canonical counts, candidate-gate decisions, or repository content. The artifact remains `not-approved` and requires a separate review and candidate-gate process.
