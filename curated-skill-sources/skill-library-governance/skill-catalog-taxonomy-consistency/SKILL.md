# Skill Catalog Taxonomy Consistency

## Goal

Prevent a library from reporting the right total while entries point to missing, miscategorized, or non-distributed skill files.

## Inputs to inspect

JSON/Markdown catalog, source entrypoints, generated plugin tree, manifests, category map, and sync script.

## Workflow

1. Parse the machine-readable catalog and enforce unique skill names, recognized categories, valid origin values, and schema version.
2. For every authored entry, resolve the `source_path`; for every cataloged skill, confirm the corresponding generated entrypoint exists at its derived bundle path.
3. Compare actual distinct generated `SKILL.md` directories to catalog count, checking exact duplicates, near-duplicate alerts, and namespaced collisions separately.
4. Verify plugin and marketplace versions/descriptions, README totals, roadmap remaining count, and category labels generated by the current sync script.
5. Report mismatches by path and field, fix at the source-of-truth layer, regenerate output, and repeat the check from a clean checkout when available.

## Validation checklist

- [ ] JSON and Markdown catalogs agree on total, categories, and names.
- [ ] Every authored source path and bundle entrypoint resolves.
- [ ] Generated output contains exactly the intended unique entrypoints.
- [ ] Manifest versions and count descriptions match the catalog.
- [ ] Static tree validation is distinguished from a real sync-script execution.

## Required output

Produce a machine-readable consistency report listing unique count, missing paths, duplicate names, category drift, version drift, and checks that remain unexecuted.

## Boundaries and failure handling

Do not silently rewrite source data just to make counts match; do not report a clean `--check` unless the actual script ran successfully.

When repository evidence is incomplete, label the gap explicitly and request only the missing information that changes the decision. Do not claim commands, benchmarks, tests, or runtime checks passed unless their outputs were observed.
